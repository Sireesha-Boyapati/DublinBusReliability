# Dublin Bus Service Reliability Analysis

## Project Overview

This project investigates Dublin Bus service reliability by examining scheduled and observed bus operations. It focuses on measuring service delays, analysing bus bunching, and identifying locations where delays occur frequently.

The project is being developed as part of an MSc dissertation in Information Systems with Computing.

## Research Objectives

1. Measure bus service reliability by comparing scheduled and observed arrival times.
2. Analyse bus bunching using the time intervals (headways) between consecutive buses.
3. Identify delay hotspots across bus routes, stops, and time periods.
4. Present the findings through an interactive web-based dashboard.
